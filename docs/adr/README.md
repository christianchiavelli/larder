# Architecture decisions

One file per decision that was not obvious, and that someone will want to argue with later. Each records what was in front of us, what we chose, and what it costs — the cost as much as the benefit, because a decision with no cost was not a decision.

They are not edited after the fact. A decision that changes gets a new record that supersedes the old one, so the reasoning of the time survives the reasoning of now.
